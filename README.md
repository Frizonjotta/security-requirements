# Faculdade Fasipe — Requisitos de Segurança

## Sobre

Este projeto apresenta uma análise dos requisitos de segurança do sistema acadêmico fictício da Faculdade Fasipe.

## Aplicação

O sistema é utilizado por alunos, professores e administradores para consultar e gerenciar informações acadêmicas, notas, faltas e documentos.

## Objetivo

Identificar requisitos que podem melhorar a segurança da aplicação e reduzir possíveis riscos.
